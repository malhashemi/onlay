# Onlay — Brand Card

Portable brand values for surfaces where CSS doesn't reach — print, native
decks, documents, email templates, third-party tools. The tokens in `tokens/`
are the source of truth; this card is their travel form. Keep the two in sync
(the Colors section is regenerated by `build-palette.py --card`; the rest is
maintained by hand — log changes in the readme changelog).

## One-liner

Onlay is the browser extension where humans and agents ask, comment, anchor, and edit through any web page.

## Naming

Written form in prose is **Onlay** (capitalized). Lowercase `onlay` is reserved for technical identifiers — the CLI binary, packages, paths, and code.

## Type

Instrument-panel posture: engineered sans + mono, compact and precise.

- Display: IBM Plex Sans intended; fallback stack `Aptos`, `Segoe UI Variable`, `Segoe UI`, system sans — headings, brand moments, section labels.
- Body: IBM Plex Sans intended; same fallback stack — product UI, docs, prose, extension chrome.
- Mono: IBM Plex Mono intended; fallback stack `SF Mono`, `SFMono-Regular`, `ui-monospace`, `Menlo`, `Consolas` — shortcuts, IDs, code, route/state labels, tokens.
- Font assets: IBM Plex Sans and IBM Plex Mono are self-hosted in `assets/fonts/` and wired through `tokens/typography.css`.
- Scale: xs 12px · sm 13.3px · base 16px · md 19.2px · lg 23px · xl 27.6px · 2xl 33.2px · 3xl fluid 36–48px.
- Weights: regular 400 · medium 500 · semibold 600 · bold 700.

## Spacing & shape

- Spacing rhythm: compact 4px base steps, with product rows at 8–12px, panels at 16px, sections at 32px.
- Corner radius: xs 4px · sm 6px · md 8px · control 10px · panel 12px · xl 16px · full pills/orb.
- Shadow/ring: shadows are dark-chrome depth; focus and anchors use outline rings, never fills.
- Rule of thumb: dense enough for agent/operator work, spacious enough that attention rows and anchors never feel like ads.

## Marks & assets

- Logo files: `assets/logo.svg` is THE mark, used at every size (two-tone: primary-600 `#007886` boundary, primary-500 `#00C4D7` core); `assets/logo-mono.svg` is the same drawing in one ink for one-color contexts. One mark, everywhere — no simplified variants. The original mark-3 trace and runner-ups live under `assets/logo-lab/`.
- Clear-space rule: minimum one inner-dot diameter around the symbol. The launcher orb wears the mark (the orb IS the mark in product-control dress — status dot and badge are the only additions); on brand surfaces the mark stands free, since filled-circle containers read as the orb.
- Mark story (DR-009 in geometry): boundary ring = Onlay's layer, broken open where an agent waits; loose signal = an unanchored Ask holding the break; context ring = the page's context made visible; anchored point + needle = human judgment reaching toward the signal — Anchor.
- Signature elements: `assets/signature-elements.css` defines `.onlay-signal-orb`, `.onlay-anchor-ring`, and `.onlay-kind-chip` specimens.
- Icon system: lucide-style outline geometry, 1.75–2px stroke, 16px rows / 20px panels / 24px command icons. Humans are round avatars; agents are squared avatars.
